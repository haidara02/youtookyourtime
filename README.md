# You Took Your Time
E-commerce Platform  for the You Took Your Time clothing brand

## Stack

- **Framework:** Next.js 16 (App Router) with Payload CMS 3
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Domain:** youtookyourtime.com (via Cloudflare DNS)

## Prerequisites & Setup

- Node.js 18+ and pnpm

First, install dependencies, copy environment variables and run the development server:

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
